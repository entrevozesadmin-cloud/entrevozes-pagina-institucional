# ENTREVOZES | Página Institucional

Página institucional do projeto EntreVozes: uma iniciativa independente para aproximar conhecimentos psicológicos da sociedade.

## Como funciona

- Página estática, criada com HTML, CSS e JavaScript puros.
- Não hospeda nem reproduz episódios. O Spotify é a plataforma exclusiva de publicação dos episódios em áudio.
- Não possui login, cadastro, banco de dados, painel ou formulário.
- Não exige instalação de dependências nem serviços pagos.

## Configurações

No arquivo script.js, WHATSAPP_NUMBER define o contato institucional e SPOTIFY_URL define o perfil oficial do Spotify. Com um endereço válido configurado, o botão direciona ao perfil. Sem ele, permanece visualmente inativo e não redireciona.

## Publicação e custos

O site estático pode ser mantido gratuitamente no GitHub Pages em um repositório público, usando o endereço github.io fornecido pelo GitHub. Não há domínio pago, hospedagem contratada, APIs pagas ou cobrança recorrente prevista. As fontes Cormorant Garamond e Inter são carregadas pelo Google Fonts sem custo, com alternativas locais caso o serviço esteja indisponível.

## Nota editorial

O conteúdo tem caráter educativo e informativo. Não substitui acompanhamento psicológico individualizado e a EntreVozes não se apresenta como clínica ou serviço de atendimento psicológico.
